## 一、发明名称

一种从主焦点坐标系目标点反解液滴发生器位移台六自由度指令的方法及系统

（备选名：基于"固定安装标定段 + 可命令六自由度段"双段分解的液滴发生器喷嘴对准控制方法）

---

## 二、技术领域

本发明涉及激光等离子体（LPP）极紫外（EUV）光刻光源的锡液滴源喷嘴对准与精密位移台控制技术，具体涉及一种在主焦点坐标系（PFCS）中指定落点目标、并据此反向求解液滴发生器位移台（DGS）六自由度运动指令的方法及实现该方法的系统。

---

## 三、背景技术

LPP-EUV 光源通过驱动激光轰击位于主焦点（Primary Focus，PF）处的高温锡液滴，激发等离子体产生 13.5 nm 极紫外辐射。为获得稳定的 EUV 输出，由液滴发生器（Droplet Generator, DG）的喷嘴（Nozzle）喷出的锡液滴，其飞行轨迹必须精确穿过 PF，使其与驱动激光在 PF 处会合。

为实现并维持这一对准，喷嘴本体安装在一台六自由度（6-DOF：三平移 Tx/Ty/Tz、三转动 Rx/Ry/Rz）精密位移台——液滴发生器位移台（Droplet Generator Stage, DGS）——之上。系统集成时，DGS 以某一安装姿态固定于光源机器结构上；运行时，控制系统向 DGS 下发 6-DOF 指令，刚性地平移/转动整个喷嘴，从而改变液滴的喷射位置与方向，使液滴落点在 PF 附近可调并被锁定。

在工程实现中存在多个相互关联的坐标系：机器坐标系（MCS，光源整机基准）、主焦点坐标系（PFCS，以 PF 为原点，是光学上有意义的基准系）、DGS 坐标系（DGSCS，DGS 自身基准）、以及 DGS 局部坐标系（DGSLCS，随 DGS 命令位姿运动的喷嘴局部系）。喷嘴出口在 DGSLCS 下的几何（位置与喷射方向）由设计固定；DGS 在机器上的安装姿态在系统集成时一次性确定但含有不可避免的安装偏差。

因此，"使液滴到达 PFCS 中给定目标点"这一控制需求，本质上是：在已知 DGS 安装标定与喷嘴固定几何的前提下，求解一组满足行程约束与机构耦合约束的 6-DOF 指令，使被刚性变换后的喷嘴喷射的液滴轨迹通过该目标点。

## 四、现有技术存在的问题（拟解决的技术问题）

申请人在工程实践中发现，对上述喷嘴对准/落点反解问题，现有做法存在以下技术问题：

1. **安装偏差与运行指令耦合**。若将"喷嘴局部系 → 光学基准系"的整条变换视为单一变换处理，则 DGS 的固定安装偏差与运行期可命令量被混在同一变换中。一旦重新标定安装姿态，或需要在线复解指令，都要重算整链，标定结果难以复用，在线计算负担大。

2. **目标基准系不当**。落点目标常以机器坐标系或台架坐标系给定，而真正具有光学意义的是 PF（即 PFCS 原点）。以非光学基准系指定目标，需在控制回路外额外做坐标换算，且 FDS（精探测系统）的监测参考点亦定义于 PFCS，基准不统一导致误差来源增加。

3. **忽略耦合轴可达性**。6-DOF 位移台的各轴在机构上通常相互耦合，仅校验"每个单轴指令是否在其行程极限内"是必要而非充分条件——存在各单轴均在程内、但联合姿态在机构耦合工作空间外、实际不可达的指令。直接下发此类指令会导致执行失败甚至机构干涉。

4. **标定流程与在线复解割裂**。系统集成期的喷嘴标定对准，与运行期闭环锁定时的指令在线复解，往往采用两套不同的方法/工具，增加实现与维护成本，且二者结果不一致时难以排查。

5. **示教/试凑对准效率低**。靠人工示教或试凑逐步逼近对准，过程慢、依赖经验、不可泛化到不同目标点（如从 PF 切换到监测点），也难以支撑闭环实时复解。

---

## 五、发明目的

针对上述问题，本发明的目的在于提供一种从 PFCS 目标点反解 DGS 六自由度指令的方法及系统，使得：

- 在光学基准系（PFCS）中直接指定落点目标；
- 将坐标变换显式分解为"系统集成期一次标定的固定段"与"运行期可命令的 6-DOF 段"，使安装标定可独立复用、在线复解为局部问题；
- 通过对固定段求逆，把 PFCS 目标"拉回"DGS 自身坐标系后再求解可命令段，得到闭式/解析的指令；
- 以"单轴行程极限（必要条件）+ 耦合工作空间可达性（充分条件）"两级判据校验指令可行性，对不可达情形给出失败报告并触发回退；
- 用同一套方法统一覆盖系统集成期标定对准与运行期闭环在线复解。

## 六、技术方案

### 6.1 坐标系与变换链定义

定义四个右手正交坐标系，构成以 MCS 为根的变换树（约定旋转角正方向遵循右手定则）：

```
MCS (根, 机器坐标系)
 └─ PFCS  : 经固定变换 T(α, L_op) 关联到 MCS, 原点为 PF
     └─ DGSCS : 经固定变换 T_ps 关联到 PFCS
         └─ DGSLCS : 经可命令变换 T_sl 关联到 DGSCS, 随 6-DOF 指令运动
```

各点坐标在父、子系间的关系统一为：`[p]_父 = M · [p]_子`，其中 M 为子系的变换矩阵（采用 4×4 齐次/3×3 旋转 + 3×1 平移的仿射变换表示）。

记：
- `P_l`：喷嘴出口在 DGSLCS 下的位置（设计固定，已知）；
- `d_l`：喷嘴喷射方向在 DGSLCS 下的单位向量（设计固定，已知）；
- `P_p`：PFCS 下指定的目标点（如 PF=(0,0,0)，或 FDS 监测点 monitorPosition）；
- `T_sl`：DGSLCS→DGSCS 的**可命令**仿射变换，由 6 个指令量 (yaw α, pitch β, roll γ, tx, ty, tz) 决定；
- `T_ps`：DGSCS→PFCS 的**固定**仿射变换，由安装标定量决定。

### 6.2 正向运动学链

喷嘴出口在 PFCS 下的位置由下式给出（正向链）：

```
P_p = T_ps · T_sl · P_l
```

可命令段 `T_sl` 的旋转矩阵按 R = Rz(α)·Ry(β)·Rx(γ) 构造（c=cos, s=sin）：

```
        [ cα·cβ      cα·sβ·sγ − sα·cγ     cα·sβ·cγ + sα·sγ ]
R_sl =  [ sα·cβ      sα·sβ·sγ + cα·cγ     sα·sβ·cγ − cα·sγ ]
        [  −sβ          cβ·sγ                cβ·cγ          ]
平移列 t_sl = (tx, ty, tz)
```

固定段 `T_ps` 由安装标定量构造。安装标定包含两个安装角与平移量：连接 PFCS↔MCS 的安装角 αᵢ、连接 MCS↔DGSCS 的安装角 βᵢ，以及由标定原始量导出的平移列 `L_ps`（其定义为 DGS 原点在 PFCS 下相对 PF 的位移向量）。其旋转部分为：

```
        [   0        cβᵢ          sβᵢ       ]
R_ps =  [ −cαᵢ      −sαᵢ·sβᵢ      sαᵢ·cβᵢ   ]
        [  sαᵢ      −cαᵢ·sβᵢ      cαᵢ·cβᵢ   ]
平移列 t_ps = L_ps
```

> 说明：T_ps 由 PFCS↔MCS 与 MCS↔DGSCS 两段固定关系复合而成，其平移列等于位移向量 L_ps；L_ps 由标定原始量（PF 点与 DGS 原点在 MCS 下的坐标）按 `L = 终点位置 − 起点位置` 并经安装角旋转导出，三者满足标定一致性约束（见实施例一）。

### 6.3 核心：固定段 / 可命令段的双段分解

本发明的核心在于：**不把整条 DGSLCS→PFCS 变换作为单一对象处理，而是显式分解为两段**——

- **固定标定段 T_ps（DGSCS→PFCS）**：仅由 DGS 在机器上的安装姿态决定，于系统集成期一次性标定填入，运行期视为常量。该段吸收了 DGS 的全部"as-built"安装偏差。
- **可命令段 T_sl（DGSLCS→DGSCS）**：仅由运行期 6-DOF 指令决定，是真正被控制器实时改变的量。

由此，整链写为 `T_pl = T_ps · T_sl`。这一分解带来两个直接后果：(a) 重新标定安装姿态时只需更新 T_ps，T_sl 的求解逻辑不变；(b) 反解时可先对固定段求逆，将目标"拉回"DGS 自身坐标系，把全局反解问题化为 DGS 本地的局部问题。

### 6.4 反解算法（从 PFCS 目标点到 6-DOF 指令）

给定 PFCS 目标 `P_p`、喷嘴固定几何 (`P_l`, `d_l`)、以及标定得到的 `T_ps`，求一组 6-DOF 指令 (α, β, γ, tx, ty, tz) 使 `T_ps · T_sl · P_l = P_p` 成立且可行。步骤如下：

**步骤 S1（加载标定）**：读取安装标定量 αᵢ、βᵢ、L_ps，构建固定段 `T_ps`。

**步骤 S2（指定目标）**：在 PFCS 中给定目标点 `P_p`（如 PF 或监测点）。

**步骤 S3（对固定段求逆并拉回目标）**：计算 `T_sp = invert(T_ps)`（刚体逆：旋转取转置、平移取 `−R_psᵀ·t_ps`），令

```
P_s = T_sp · P_p
```

`P_s` 即"为使液滴到达 P_p，喷嘴出口应在 DGSCS 下到达的位置"。此步把 PFCS 全局目标转化为 DGS 自身坐标系内的本地目标，与 DGS 安装姿态解耦。

**步骤 S4（求解可命令段 T_sl）**：在 DGSCS 中，求 T_sl 使

```
R_sl · P_l + t_sl = P_s          （位置约束，3 个标量方程）
```

成立。该约束仅含 3 个方程而 T_sl 含 6 个自由度，故为欠定问题；本发明给出三种冗余消解方式（见 6.6），并以"位姿目标"方式（同时约束喷射方向）作为完整约束的优选实施。

**步骤 S5（提取欧拉角与平移量）**：从所得 `R_sl` 的 3×3 子矩阵按 ZYX 顺序反解三个角，从其平移列取三个平移量：

```
β (pitch) = atan2( −r31,  sqrt(r11² + r21²) )
α (yaw)   = atan2(  r21,  r11 )
γ (roll)  = atan2(  r32,  r33 )
(tx, ty, tz) = t_sl
```

当 cβ ≈ 0（万向锁奇异）时，按预设规则（如令 γ=0）确定一组等效解。所得 (α, β, γ, tx, ty, tz) 即候选 DGS 指令。

**步骤 S6（两级可达性校验）**：对候选指令依次校验——
- 第一级（必要条件，单轴行程极限）：每个 tx/ty/tz/α/β/γ 落在各自行程区间 [min, max] 内；
- 第二级（充分条件，耦合工作空间可达性）：由机构运动学/标定表判定该组联合姿态是否落在 DGS 实际可达的耦合工作空间内。

两级均通过则进入 S7；任一级不通过则报告"反解失败/目标不可达"，触发回退目标（如允许液滴不经监测点而仅命中目标点）或安全响应。

**步骤 S7（下发指令）**：将通过校验的 (α, β, γ, tx, ty, tz) 封装为 DGS 指令，经控制端口下发执行。

### 6.5 算法流程（伪代码）

```
function SolveDGSCommandFromPFTarget(P_p, P_l, d_l, calib):
    T_ps  = BuildFixedStage(calib.alpha_i, calib.beta_i, calib.L_ps)   # S1
    T_sp  = Invert(T_ps)                                               # S3
    P_s   = Apply(T_sp, P_p)                                           # S3
    d_s   = Rotate(T_sp, d_l_target_direction)   # 位姿目标模式下使用    # S4
    T_sl  = SolveCommandableStage(P_s, P_l, d_s, d_l)                  # S4
    (a,b,g,tx,ty,tz) = ExtractEulerAndTranslation(T_sl)               # S5
    if not SingleAxisInRange(a,b,g,tx,ty,tz):     return FAIL_RANGE    # S6-1
    if not CoupledWorkspaceReachable(a,b,g,tx,ty,tz): return FAIL_WS   # S6-2
    IssueCommand(a,b,g,tx,ty,tz)                                       # S7
    return OK
```

### 6.6 冗余自由度的消解（三种实施方式）

单点目标约束欠定，本发明公开以下任一方式消解（均落入保护范围）：

- **(A) 位姿目标 / 方向匹配（优选）**：注意液滴轨迹是一条线（由出口位置 + 喷射方向确定），物理上需控制的是该线而非单点。故除位置约束外，附加喷射方向约束 `R_sl · d_l = d_s`（其中 `d_s = R_sp · d_p`，`d_p` 为 PFCS 下期望喷射方向，使弹道穿过目标）。方向匹配确定两个转动自由度，沿喷射轴的转动（roll）由次级判据或取标称值确定，平移量随后由位置约束唯一解出。此方式约束完整、解唯一（至多差一个轴向冗余），与 BallisticTrajectory 自洽。
- **(B) 参考位姿 + 最小运动**：在满足位置约束的解流形中，选取与标称/参考位姿距离最小（指令改动最小）的一组，经向可行集投影实现。
- **(C) 约束优化**：以代价函数（如至标称位姿的加权距离、或执行器行程占用）为目标，在位置约束与两级工作空间约束下做有约束最优化求解。

### 6.7 标定期与运行期的统一应用

同一反解方法用于两个阶段：
- **系统集成标定期**：取 `P_p = PF`，反解得到使液滴命中 PF 的指令，作为对准基准并核定可达性；
- **运行闭环期**：取 `P_p = 监测点 monitorPosition`（FDS 实时监测平面上的参考点），由 FDS 反馈的落点误差驱动在线复解 T_sl，输出修正指令实现闭环锁定。

两阶段共用 S1–S7，仅目标点 `P_p` 不同，避免了标定与在线两套方法的割裂。

## 七、有益效果

1. **标定与指令解耦、可复用**：固定段 T_ps 吸收全部安装偏差，重新标定仅更新 T_ps，运行期反解逻辑不变；在线复解被化为 DGS 本地局部问题，计算量小、利于实时。
2. **光学基准系直接指定目标**：在 PFCS 中直接给定 PF 或监测点，无需控制回路外的额外坐标换算，且与 FDS 监测基准统一，减少误差来源。
3. **闭式/解析求解、速度快**：经固定段求逆拉回 + ZYX 提取，主体为解析运算，便于在所需闭环带宽下实时执行。
4. **可行性两级把关、可回退**：单轴行程极限（必要）+ 耦合工作空间（充分）双重判据，杜绝"各轴在程但联合不可达"的指令，并对不可达情形给出明确失败信号以触发回退/安全响应。
5. **标定—运行一体化**：同一方法覆盖系统集成标定与运行在线复解，降低实现与维护成本、便于排查。

## 八、具体实施方式

### 实施例一：完整数值实施（标定期，目标 = PF）

某 LPP-EUV 锡液滴源 DGSS，DGS 行程极限为：Tx ∈ [−9, +9] mm，Ty ∈ [−10, +10] mm，Tz ∈ [−4.5, +4.5] mm，Rx ∈ [−2.1, +2.1]°，Ry ∈ [−2.4, +2.4]°，Rz ∈ [−4.3, +4.3]°，各轴相互耦合。

安装标定量（系统集成期标定填入）：
- 安装角 αᵢ = 28°（PFCS↔MCS），βᵢ = 78°（MCS↔DGSCS）；
- 标定原始量：PF 点在 MCS 下坐标 `P_in_MCS = (0, −41.524524, 1248.672688) mm`；DGS 原点在 MCS 下坐标 `S_in_MCS = (916.328834, −41.524524, 1341.435967) mm`；
- 由 `L = 终点 − 起点` 导出位移向量并经安装角旋转，得固定段平移列 `L_ps = (916.328834, 43.549721, 81.905114) mm`。三者满足标定一致性（在 0.1 µm 容差内）：

```
L_ps.x = (S − P)_x
L_ps.y = (S − P)_y · cos αᵢ + (S − P)_z · sin αᵢ
L_ps.z = (P − S)_y · sin αᵢ + (S − P)_z · cos αᵢ
```

实施步骤：按 6.4 的 S1 构建 `T_ps`（R_ps 由 αᵢ、βᵢ 给出，t_ps = L_ps）；S2 取 `P_p = PF = (0,0,0)`；S3 求 `T_sp = invert(T_ps)`，得 `P_s = T_sp · P_p`；S4 以位姿目标模式（附加方向约束，使弹道穿过 PF）解出 `T_sl`；S5 按 ZYX 提取 (α, β, γ, tx, ty, tz)；S6 先验证六个量分别落在上述行程区间内，再调用耦合工作空间判定；S7 通过后封装下发。该指令使喷嘴出口被刚性变换后，液滴轨迹穿过 PF，并作为对准基准。

> 喷嘴标称出口位置（PFCS 下）约为 (410.45, 0, 0) mm，喷射标称方向沿 −X；上述反解须使被变换后的实际出口位置与方向使弹道在 x=0 平面处的穿越点与 PF 的偏差小于设定容差（典型 < 1 µm）。

### 实施例二：运行闭环在线复解（目标 = 监测点）

取 `P_p = monitorPosition`（PFCS 下，位于 PF 上游一侧、与 PF 沿 X 偏置的 FDS 监测参考点，典型 (5,0,0) mm）。FDS 在监测平面成像测得液滴落点的横向偏差后，以该偏差更新目标或误差量，按 S3–S7 在线复解 T_sl 并输出修正指令，构成 FDS→DGS 闭环锁定。当横向稳定性达标时维持闭环，失守或超出可达范围时按 S6 失败分支退出。该实施与实施例一共用同一反解流程，仅目标点不同。

### 实施例三：位姿目标 / 方向匹配的完整约束实施

在实施例一/二基础上，明确把目标设为"期望喷嘴位姿"（位置 + 喷射方向），由位置约束 `R_sl·P_l + t_sl = P_s` 与方向约束 `R_sl·d_l = d_s` 联立。方向匹配定下两个转动自由度，余下沿喷射轴的转动取标称值或由次级判据（如最小化某轴行程占用）确定，再由位置约束解出平移列。此为约束完整、解析可解的优选实施。

### 实施例四：不可达时的回退与安全实施

当 S6 任一级判定不可达时，方法输出"反解失败"信号，控制系统执行回退：优先尝试变通目标（如允许液滴不经监测点而仅命中目标点）重新反解；若仍不可达，则触发安全响应（停喷、进入故障态、抑制驱动激光、报警并记录遥测），避免下发不可行指令导致执行失败或污染收集光学元件。

### 实施例五：系统实施

实现上述方法的系统包括：标定存储单元（存 αᵢ、βᵢ、L_ps 等固定标定量）；固定段构建单元（生成 T_ps）；求逆与拉回单元（生成 T_sp 与 P_s）；可命令段求解单元（解 T_sl）；欧拉角/平移提取单元；两级可达性校验单元（单轴行程极限 + 耦合工作空间，后者可由运动学模型或标定查找表实现）；指令下发单元（经控制端口输出）；以及与之配合的 6-DOF 位移台 DGS、喷嘴、与 FDS。各单元可由控制器软硬件实现。

## 十、关键发明点与建议保护范围

### 关键发明点

1. 将 DGSLCS→PFCS 整链显式分解为"系统集成期一次标定的固定段 T_ps"与"运行期可命令的 6-DOF 段 T_sl"，使安装标定可独立复用、在线复解化为本地问题。
2. 在 PFCS（光学基准系）中指定落点目标，并通过对固定段求逆把目标"拉回"DGS 自身坐标系，得到解析的可命令段求解。
3. "单轴行程极限（必要）+ 耦合工作空间可达性（充分）"两级可达性校验，及不可达时的失败报告与回退/安全触发。
4. 同一反解方法统一覆盖系统集成标定期（目标=PF）与运行闭环期（目标=监测点）。
5. 以位姿/方向匹配消解单点目标的冗余自由度，使解唯一且与弹道模型自洽。

### 建议权利要求结构（供代理师参考）

**独立权利要求 1（方法）**：一种液滴发生器位移台六自由度指令的求解方法，其特征在于，将喷嘴局部坐标系到主焦点坐标系的变换分解为由安装标定决定的固定段与由六自由度指令决定的可命令段；在主焦点坐标系中给定目标点；对固定段求逆以将目标点变换至位移台坐标系；据此求解可命令段并提取六自由度指令；以单轴行程极限与耦合工作空间可达性两级判据校验后下发。

**从属权利要求（要点）**：
- 引用权 1，可命令段旋转按 Rz·Ry·Rx 构造，指令角按 ZYX 顺序从旋转子矩阵提取；

## 十一、可替代实施方案（建议一并覆盖）

- **欧拉角顺序**：除 Rz·Ry·Rx（ZYX）外，可采用其他固定旋转顺序，相应调整提取公式；
- **分解切点**：固定段/可命令段的分界可置于变换树的不同节点（如把部分固定安装关系并入或拆出），只要保持"固定标定段 + 可命令段"二分实质；
- **求解方式**：可命令段可用闭式解析、解流形投影、或数值约束优化求解；
- **可达性判定**：耦合工作空间可由解析运动学、标定查找表、或学习型模型给出；
- **目标形式**：目标可为单点、位姿（点+方向）、或一条期望弹道线；
- **变换表示**：仿射变换可用 4×4 齐次矩阵、3×3 旋转+平移、或等价的旋量/四元数表示；
- **基准系命名**：坐标系数量与命名可按产品调整，只要存在"光学基准系目标 → 固定标定段求逆 → 可命令段反解"的链路。
