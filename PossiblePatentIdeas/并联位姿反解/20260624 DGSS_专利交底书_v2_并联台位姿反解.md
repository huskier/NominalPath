## 一、发明名称

一种面向极紫外光源的六自由度并联液滴台位姿反解控制方法及系统

（核心标识：基于"固定安装标定段 + 可命令六自由度段"双段分解的、在主焦点坐标系中定标并含奇点裕度可达性校验的解析反解方法）

---

## 二、技术领域

本发明涉及激光产生等离子体（LPP）极紫外（EUV）光刻光源的锡液滴源精密控制与系统工程领域，具体涉及一种针对承载液滴发生器（DG）的**六自由度并联精密位移台**（DGS，Stewart/六足型）的多坐标系归约与位姿反解控制方法及实现该方法的系统。

---

## 三、背景技术

LPP-EUV 光源通过驱动激光轰击位于主焦点（Primary Focus, PF）处的高温锡液滴激发等离子体，产生 13.5 nm 极紫外辐射。为获得稳定 EUV 输出，由液滴发生器喷嘴喷出的微米级锡液滴，其飞行轨迹必须精确穿过 PF 与驱动激光会合。

为补偿喷嘴加工误差与安装偏置并维持对准，喷嘴本体安装于一台**六自由度并联精密台**（DGS）之上。并联台以平台位姿（6-DOF：三平移 Tx/Ty/Tz、三转动 Rx/Ry/Rz）为命令接口，其内部由控制器将位姿换算为各支杆/作动器行程（此为并联机构的杆长逆解，闭式且平凡，下文不作为本发明的发明点）。系统集成时，DGS 以某一含安装偏差的姿态固定于光源机器结构；运行时，控制系统向 DGS 下发 6-DOF 位姿指令，刚性地平移/转动整个喷嘴，改变液滴喷射位姿，使液滴落点在 PF 附近可调并被闭环锁定。

并联台与坐标系带来如下工程难点：

1. **多坐标系强耦合的安装偏置**。DG 在整机中的安装存在复杂空间姿态偏置（本系统中机器基准与相关基准间含 28° 与 78° 安装夹角）。若以单坐标系或将整链合一的方式处理，安装姿态造成的轴间耦合被掩盖，导致命令下发后靶点处产生非线性空间漂移，且安装姿态一旦重新标定即需重算整链。
2. **目标基准系不当**。落点目标与 FDS（精探测系统，如高速阴影成像）的监测参考点本应在具有光学意义的主焦点坐标系（PFCS）中表达；以机器系/台架系给定目标会引入控制回路外的额外换算与误差。
3. **并联机构特有的耦合工作空间与运动学奇点**。并联台的可达位姿集并非各单轴行程区间的笛卡尔积"盒"，而是受各支杆长度极限、铰链转角极限、连杆干涉共同约束的非凸耦合空间；并联机构在特定位形存在**运动学奇点**（雅可比降秩），在此附近平台会获得不可控瞬时自由度、刚度骤降、作动力可能发散。仅校验单轴行程极限不能避免"各轴在程但联合不可达或逼近奇点"的危险指令，在狭小超高真空腔体内极易引发机构干涉或失稳损坏。
4. **标定流程与运行在线复解割裂**，及示教/试凑对准效率低、不可泛化（如从 PF 切换到监测点），难以支撑闭环实时复解。

## 四、发明目的

提供一种六自由度并联液滴台位姿反解控制方法及系统，使得：在光学基准系 PFCS 中直接指定目标；将坐标变换显式分解为系统集成期一次标定的固定段与运行期可命令的 6-DOF 段，使标定可独立复用、在线复解化为本地解析问题；通过对固定段求逆把目标"拉回"DGS 自身坐标系，配合喷嘴方向约束得到**闭式、单次、无迭代**的位姿指令；以"单轴行程极限（必要）+ 含奇点裕度的并联耦合工作空间可达性（充分）"两级判据校验，对不可达/逼近奇点情形给出失败信号并由状态机拦截、降级安全模式；并以同一方法统一覆盖集成期标定与运行期闭环复解。

## 五、技术方案（核心保护点）

### 5.1 步骤 S1：构建多级坐标系齐次变换树

建立以机器坐标系（MCS）为根的右手正交坐标系树，旋转角正方向遵循右手定则：

```
MCS (根)
 └─ PFCS  : 经固定变换 T(αᵢ, L_op) 关联到 MCS, 原点为 PF
     └─ DGSCS : 经固定变换 T_ps 关联到 PFCS
         └─ DGSLCS : 经可命令变换 T_sl 关联到 DGSCS, 随 6-DOF 位姿指令运动
```

点坐标在父、子系间统一为 `[p]_父 = M · [p]_子`，M 为子系变换（仿射：3×3 旋转 R + 3×1 平移 t）。记：`P_l`、`d_l` 为喷嘴出口在 DGSLCS 下的固定位置与喷射方向（设计常量，`d_l` 沿 DGSLCS 的 −X 轴，即 (−1,0,0)）；`T_sl` 为可命令段，由 6 指令 (yaw α, pitch β, roll γ, tx, ty, tz) 决定；`T_ps` 为固定段，由安装标定量（安装角 αᵢ、βᵢ 与平移列 L_ps）决定。

### 5.2 步骤 S2：在 PFCS 指定目标并归约为期望出口位姿

**注意喷嘴出口与主焦点间存在站位距（standoff）**：喷嘴出口标称位于 PFCS 下约 (410.45, 0, 0) mm，主焦点 PF 在 (0,0,0)，液滴自出口飞行约 410 mm 抵达 PF。因此控制目标"液滴落点命中 PFCS 中目标点 T（如 PF 或监测点）"先经弹道关系归约为**期望喷嘴出口位姿** (P_out\*, d_out\*)（PFCS 下的期望出口位置与喷射方向），使从该位姿喷出的弹道轨迹穿过 T（重力下坠小时，d_out\* 近似为由出口指向 T 的方向、经下坠修正）。本步骤将"落点目标 → 期望出口位姿"与后续"期望出口位姿 → 6-DOF 指令"分离；前者衔接弹道模型，后者（5.3–5.7）为本发明核心。

### 5.3 步骤 S3：双段分解与对固定段求逆（核心）

正向位姿链为：

```
P_out = T_ps · T_sl · P_l            （位置）
d_out = R_ps · R_sl · d_l            （方向, 仅经旋转部分变换, 不含平移）
```

将整链显式分解为**固定标定段 T_ps（集成期一次标定、运行期常量，吸收全部安装偏差）**与**可命令段 T_sl（运行期指令）**：T_pl = T_ps · T_sl。

对固定段求逆（刚体逆：R_sp = R_psᵀ，t_sp = −R_psᵀ · t_ps），把期望出口位姿"拉回"DGSCS：

```
P_s = T_sp · P_out\* = R_sp · P_out\* + t_sp      （DGSCS 下期望出口位置）
d_s = R_sp · d_out\*                              （DGSCS 下期望出口方向, 仅旋转）
```

此步把 PFCS 全局目标转为 DGS 自身坐标系内的本地目标，与安装姿态解耦——重新标定仅更新 T_ps，下式求解逻辑不变。

### 5.4 步骤 S4–S5：可命令段的闭式解析解（无迭代）

在 DGSCS 中求 T_sl 使位置约束 `R_sl·P_l + t_sl = P_s` 与方向约束 `R_sl·d_l = d_s` 同时成立。可命令段旋转按 R = Rz(α)·Ry(β)·Rx(γ) 构造：

```
        [ cα·cβ      cα·sβ·sγ − sα·cγ      cα·sβ·cγ + sα·sγ ]
R_sl =  [ sα·cβ      sα·sβ·sγ + cα·cγ      sα·sβ·cγ − cα·sγ ]
        [  −sβ            cβ·sγ                 cβ·cγ        ]
```

**关键解耦结构（本方法实时性的根据）**：因 `d_l = (−1,0,0)`，有

```
R_sl · d_l = −(R_sl 第一列) = (−cα·cβ, −sα·cβ, sβ) = d_s
```

R_sl 第一列 `(cα·cβ, sα·cβ, −sβ)` **不含 γ**。即喷射方向 d_s 仅由偏航 α 与俯仰 β 决定，与绕喷嘴轴的 roll γ **完全无关**（已数值核验，残差 ~1e-16）。由此得**闭式解**：

```
β (pitch) = atan2( d_s.z,  sqrt(d_s.x² + d_s.y²) )          // = asin(d_s.z), cβ ≥ 0
α (yaw)   = atan2( −d_s.y, −d_s.x )
γ (roll)  = 0                                               // 锁死冗余轴(见 5.5(A))
```

（其中 `sqrt(d_s.x² + d_s.y²) = |cβ|`，因 d_s.x²+d_s.y² = cβ²(cα²+sα²) = cβ²。）

确定 (α, β, γ) 后构建 R_sl，再由位置约束直接解出平移列（单次减法）：

```
t_sl = (tx, ty, tz) = P_s − R_sl · P_l
```

**至此六个指令量 (tx, ty, tz, roll=γ, pitch=β, yaw=α) 由反三角函数与一次矩阵-向量运算单次解出，无需任何迭代优化。** 方程计数：方向约束提供 2 个独立方程（单位向量）定 (α,β)，roll 锁死提供 1 个，位置约束提供 3 个定 (tx,ty,tz)，共 6 个独立约束对应 6 个未知量，**适定且唯一**。

**奇异分支（公开充分性）**：当 cβ ≈ 0（β ≈ ±90°，喷嘴指向 DGSCS 的 ±Z）时 α 的 atan2 退化；但该位形远在本台俯仰行程（典型 Ry ∈ [−2.4°, +2.4°]）之外，正常运行不可达，必要时按约定（如保持上一拍 α）处理。

### 5.5 冗余自由度的消解（择一，均落入保护范围）

- **(A) 锁死绕喷嘴轴自转（优选）**：准直圆喷嘴绕自身物理轴线（DGSLCS 的 X 轴，对应 Rx=γ=commandedRoll）的转动对液滴喷出轨迹与落点无物理贡献，故显式令 γ=0（或取常量/参考值），完美闭合方程。
- **(B) 并联奇点裕度寻优**：注意即便 γ 不改变液滴结果，它会改变并联台位姿，从而改变支杆位形与至运动学奇点的距离。故可在 γ（及位置约束允许的零空间）上寻优，使所选位形的**奇点裕度最大**（如使雅可比条件数 κ(J) 最小或 |det(J)| 最大）。
- **(C) 作动行程寻优**：在满足 P_out\*、d_out\* 的解集中，求使各作动器移动量平方和 `min Σ Δℓᵢ²` 最小、或最远离单轴行程极限的一组解（数值/优化法路径）。

### 5.6 步骤 S6：双重物理边界与并联奇点裕度校验

下发前对候选指令两级校验——
- **第一级（必要条件，单轴行程极限）**：tx/ty/tz/α/β/γ 分别落在各自行程区间内（如 tx ∈ [−9, +9] mm、Ry ∈ [−2.4°, +2.4°] 等）。
- **第二级（充分条件，并联耦合工作空间可达性，含奇点裕度）**：由并联机构运动学/标定表判定该联合位姿是否落在实际可达的耦合工作空间内——即同时满足各支杆长度极限、铰链转角极限、**无连杆干涉**，且与运动学奇点集保持设定裕度（雅可比条件数低于阈值 / 局部灵巧度高于阈值）。

任一级不通过则输出"反解失败/不可达/逼近奇点"，由控制状态机（State Machine）拦截、拒绝下发，并触发回退（优先尝试变通目标重解）或降级安全模式（停喷、进入故障态、抑制驱动激光、报警并记录遥测），保护超高真空内机构装配安全。

### 5.7 步骤 S7：下发与标定—运行一体化

将通过校验的 6-DOF 位姿指令封装经控制端口下发并联台执行（台内完成杆长逆解驱动作动器）。同一流程 S1–S7：集成标定期取目标 = PF 作对准基准；运行闭环期取目标 = 监测点 monitorPosition，由 FDS 反馈落点横向偏差驱动在线复解，构成 FDS→DGS 闭环锁定，避免标定与在线两套方法割裂。

### 5.8 算法流程（伪代码）

```
function SolvePoseCommand(T_target, P_l, d_l, calib):
    (P_out*, d_out*) = BallisticReduce(T_target)          # S2: 落点→期望出口位姿
    T_ps  = BuildFixedStage(calib.alpha_i, calib.beta_i, calib.L_ps)   # S1
    T_sp  = Invert(T_ps)                                  # S3: R^T, -R^T t
    P_s   = R(T_sp)·P_out* + t(T_sp)                      # S3
    d_s   = R(T_sp)·d_out*                                # S3 (仅旋转)
    beta  = atan2(d_s.z, sqrt(d_s.x^2 + d_s.y^2))         # S4 闭式
    alpha = atan2(-d_s.y, -d_s.x)                         # S4 闭式
    gamma = 0    # 或 (B)/(C) 寻优                         # S5
    R_sl  = Rz(alpha)·Ry(beta)·Rx(gamma)
    t_sl  = P_s − R_sl·P_l                                # S4 直解
    (tx,ty,tz) = t_sl
    if not SingleAxisInRange(tx,ty,tz,alpha,beta,gamma): return FAIL_RANGE   # S6-1
    if not CoupledReachableWithSingularityMargin(...):    return FAIL_WS     # S6-2
    IssueCommand(tx,ty,tz, roll=gamma, pitch=beta, yaw=alpha)               # S7
    return OK
```

## 六、有益效果

1. **解耦精度高**：固定段 T_ps 吸收全部跨坐标系安装偏置，彻底消除整链合一带来的轴间耦合漂移；重新标定仅更新 T_ps，运行期反解逻辑不变。
2. **光学基准系直接定标**：在 PFCS 中直接指定 PF/监测点，与 FDS 监测基准统一，免去回路外换算与相应误差。
3. **闭式、单次、确定性求解**：由方向解耦得到 atan2 闭式解（无迭代），平移一次减法解出。计算时间确定且有界，**充分满足 ≥5 Hz 闭环带宽预算并留有提升余量**。（说明：本方法不以"亚微秒级解算"为闭环稳定的前提；5 Hz 带宽对应约 200 ms 时间尺度，确定性单次解算的价值在于消除迭代不确定性与为更高带宽留余量，而非渲染相位延迟。）
4. **并联机构安全性高**：将单轴行程极限（必要）与含**奇点裕度**的并联耦合工作空间可达性（充分）两级判据无缝嵌入实时控制流，避免"各轴在程但联合不可达/逼近奇点"导致的狭小真空腔内机构干涉、刚度骤降与作动力发散等灾难性失效。
5. **标定—运行一体化**：同一方法覆盖集成期标定与运行在线复解，降低实现/维护成本、便于排查。

## 七、具体实施方式

### 实施例一：完整数值实施（集成标定期，目标 = PF）

某 LPP-EUV 锡液滴源 DGSS，DGS 为六自由度并联台，位姿行程极限：Tx ∈ [−9, +9] mm，Ty ∈ [−10, +10] mm，Tz ∈ [−4.5, +4.5] mm，Rx ∈ [−2.1, +2.1]°，Ry ∈ [−2.4, +2.4]°，Rz ∈ [−4.3, +4.3]°，各轴经并联机构耦合。

安装标定量：αᵢ = 28°（PFCS↔MCS），βᵢ = 78°（MCS↔DGSCS）；标定原始量 `P_in_MCS = (0, −41.524524, 1248.672688) mm`、`S_in_MCS = (916.328834, −41.524524, 1341.435967) mm`；由 `L = 终点 − 起点` 并经安装角旋转导出固定段平移列 `L_ps = (916.328834, 43.549721, 81.905114) mm`，满足标定一致性（0.1 µm 容差内）：

```
L_ps.x = (S − P)_x
L_ps.y = (S − P)_y · cos αᵢ + (S − P)_z · sin αᵢ
L_ps.z = (P − S)_y · sin αᵢ + (S − P)_z · cos αᵢ
```

固定段旋转（αᵢ=28°, βᵢ=78°，已核验正交）：

```
        [   0        cβᵢ           sβᵢ        ]      [   0       0.20791    0.97815 ]
R_ps =  [ −cαᵢ      −sαᵢ·sβᵢ       sαᵢ·cβᵢ    ]  ≈  [ −0.88295  −0.45921   0.09761 ]
        [  sαᵢ      −cαᵢ·sβᵢ       cαᵢ·cβᵢ    ]      [  0.46947  −0.86375   0.18357 ]
t_ps = L_ps
```

实施：取期望出口位姿 P_out\* = nominalNozzlePosition = (410.453510, 0, 0) mm、d_out\* ≈ (−1, 0, 0)（指向 PF、经下坠修正）。按 S3 求 T_sp 并得 P_s、d_s；按 S4 闭式得 β=atan2(d_s.z, √(d_s.x²+d_s.y²))、α=atan2(−d_s.y, −d_s.x)、γ=0；构建 R_sl 后 t_sl = P_s − R_sl·P_l 得 (tx,ty,tz)。S6 先验证六量在上述区间内，再调用并联耦合工作空间+奇点裕度判定。S7 通过后封装下发，作为对准基准。（P_l = 喷嘴出口在 DGSLCS 下的设计固定位置，按实际几何代入。）

### 实施例二：运行闭环在线复解（目标 = 监测点）

取目标 = monitorPosition（PFCS 下、PF 上游沿 X 偏置的 FDS 监测参考点，典型 (5,0,0) mm）。FDS 高速阴影成像测得液滴落点横向偏差后，更新期望出口位姿或误差量，按 S3–S7 在线闭式复解并输出修正指令，构成 FDS→DGS 闭环锁定；横向稳定性达标时维持闭环，失守或逼近奇点/超可达范围时按 S6 失败分支退出。与实施例一共用同一闭式流程，仅目标不同。

### 实施例三：奇点裕度寻优实施（消解冗余 roll）

在实施例一/二基础上，不取 γ=0，而在 γ 上寻优使所选并联位形的雅可比条件数 κ(J) 最小（远离奇点），在液滴落点/方向结果不变的前提下提升机构刚度与控制稳定性——体现"冗余轴用于并联机构奇点回避"的实施。

### 实施例四：系统实施

实现系统包括：弹道归约单元（落点目标→期望出口位姿）；标定存储单元（αᵢ、βᵢ、L_ps）；固定段构建与求逆单元（T_ps、T_sp）；闭式反解单元（atan2 求 α/β、roll 消解、t 直解）；两级校验单元（单轴行程极限 + 并联耦合工作空间含奇点裕度，后者由运动学模型或标定查找表实现）；状态机拦截与安全降级单元；指令下发单元（经控制端口）；及六自由度并联台 DGS、喷嘴与 FDS。可由控制器软硬件实现。

## 九、关键发明点与建议保护范围

### 关键发明点

1. 将 DGSLCS→PFCS 整链显式分解为"集成期一次标定的固定段 T_ps"与"运行期可命令的 6-DOF 段 T_sl"，使安装标定可独立复用、在线复解化为本地问题。
2. 在 PFCS（光学基准系）中定标，经对固定段求逆把期望出口位姿拉回 DGSCS。
3. 利用喷嘴方向沿 DGSLCS 某坐标轴这一结构，使喷射方向与绕喷嘴轴 roll 解耦，从而由 atan2 **闭式、单次、无迭代**求 (α,β)，roll 消解后平移一次减法直解——支撑实时性。
4. "单轴行程极限（必要）+ 含**运动学奇点裕度**的并联耦合工作空间可达性（充分）"两级校验，及失败时状态机拦截与安全降级。
5. 利用冗余 roll（对液滴无影响但改变并联位形）进行**奇点回避寻优**。
6. 同一方法统一覆盖集成标定与运行闭环复解。

### 建议权利要求结构（供代理师参考）

**从属权利要求（要点）**：
- 引用权 1，可命令段旋转按 Rz·Ry·Rx 构造；利用喷嘴方向沿局部系某坐标轴使方向与该轴 roll 解耦，由 atan2 闭式求偏航与俯仰、平移由 t=P_s−R·P_l 单次解出，全程无迭代；

## 十、可替代实施方案（建议一并覆盖）

- 欧拉角顺序可取其他固定顺序，相应调整提取公式；喷嘴方向沿局部系任一坐标轴时方向-roll 解耦结论同理成立（沿非坐标轴时退化为一般 ZYX 提取，仍闭式可解）；
- 固定段/可命令段分界可置于变换树不同节点，只要保持"固定标定段 + 可命令段"二分实质；
- 可命令段求解可用闭式解析、解流形投影或数值约束优化；
- 并联耦合工作空间与奇点裕度可由解析运动学、标定查找表或学习型模型给出；
- 目标可为单点、位姿（点+方向）或一条期望弹道线；
- 仿射变换可用 4×4 齐次矩阵、3×3 旋转+平移或旋量/四元数表示；
- 坐标系数量与命名可按产品调整，只要存在"光学基准系目标 → 固定段求逆 → 可命令段解析反解 → 含奇点裕度可达性校验"的链路。

## 十一、与最接近现有技术的区别及检索建议

> 诚实声明：本交底书撰写时**未进行在先专利/文献检索**。LPP-EUV 液滴源喷嘴对准/导引及并联精密台领域专利密集（涉及 ASML/Cymer、Gigaphoton 及并联机构厂商等），请代理师撰写前完成检索以确定可保护范围与权项边界。

**与经典逆运动学的层次区别（重要）**：
- 经典**串联**机器人逆解：由末端位姿求关节角。
- 经典**并联**（Stewart/六足）平台：其"位姿→杆长"逆解是**闭式、平凡**的（每杆长 = 两连接点间距），通常由平台自身控制器在**台内**完成；困难的是"杆长→位姿"正解（一般需数值迭代、可多解）。
- **本发明所处层次在并联台"位姿→杆长"逆解之上（upstream）**：本发明解决的不是杆长逆解，而是 (a) 从光学基准系（PFCS）落点目标到并联台 6-DOF 位姿指令的**跨坐标系归约**（双段分解 + 固定段求逆 + 方向解耦的 atan2 闭式提取），以及 (b) 保证该位姿指令落在该并联机构含奇点裕度的**耦合工作空间**内。台子拿到位姿指令后由其内部（平凡的）杆长逆解驱动作动器。故区别在于：本发明是"光学系落点 → 并联台位姿指令"的归约与可达性保障层，而非并联机构本身的杆长逆解（后者为已知技术、台内完成）。

申请人初步判断的其他区别：相较"整链单一变换 + 单轴限位校验 + 标定/在线两套方法"的常规做法，本发明区别在于固定段/可命令段显式双段分解、PFCS 期望出口位姿经固定段求逆的解析反解、方向-roll 解耦带来的闭式单次求解、含奇点裕度的两级可达性校验与失败降级、以及标定—运行一体化。

建议检索关键词（中英）：
- EUV droplet generator nozzle alignment / steering；hexapod / Stewart platform inverse pose command；optical-frame coordinate reduction；parallel manipulator singularity avoidance workspace；closed-form analytic pose solution atan2 nozzle direction decoupling；calibration decomposition fixed commandable transform。
- 极紫外/EUV 液滴源 喷嘴对准/导引；六自由度并联台 位姿指令；主焦点 坐标系 归约；并联机构 奇点 回避 工作空间；解析闭式 反解 atan2 方向解耦；安装标定 与 运行指令 分离。
